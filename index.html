    Where the files go
    
    
    
      
    
        
    user.cfg
    
        
    The game's install folder, in the same folder as bf4.exe:
    
        
    
        
      
          
    • EA app: right-click the game > View properties > Browse.
      • 
          
    • Steam: right-click the game > Manage > Browse local files.
      • 
          
    • Make sure Windows doesn't save it as user.cfg.txt.
      • 
        
    
      
    
      
    
        
    PROFSAVE_profile
    
        
    Your Documents folder:
    
        
    
        
      
          
    • Close the game first. It rewrites this file when it exits.
      • 
          
    • Back up the old file before replacing it.
      • 
          
    • Changing video options in-game later overwrites these values.
      •
